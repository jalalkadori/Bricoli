🛠️ Bricoli – Handyman Booking Platform
Technology used: PHP • MySQL • HTML/CSS • JavaScript
Project type: Final-year web application (PFE)

Overview:
Bricoli is an online platform that connects handymen (plumbers, electricians, painters, etc.) with individuals who need home renovation or repair services.

Users can:

Browse local professionals by specialty

View profiles, ratings, and availability

Book appointments online based on location and time

Contact service providers directly through the platform

Purpose:
To make it easier and faster for users to find reliable handymen for their renovation needs — and help professionals reach new clients.

What I learned:
✔ Full-stack development in PHP (CRUD, authentication, role-based access)
✔ Building an intuitive UI/UX focused on simplicity
✔ Managing user data and bookings securely via MySQL
✔ Designing practical features with real-world application (search filters, profile management)
